# 2.9 Reference: the weekly routine

## Today cards
| Card | Built from |
|---|---|
| Next step per initiative | each initiative's `next`, grouped by skill |
| Gates needing attention | validate-prd FAIL, validate-hld BLOCKED / manual review, spec PR open, required UX brief missing |
| Story readiness | cached DoR checks; epics past the PRD gate never checked |
| Objectives at risk | health behind; KRs without baseline / target or with readings older than 14 days |
| Open blockers & risks | the log |
| Backlog hygiene | NEEDS INFO epics, drafts not yet in Jira |
| Retros pending | retros opened on closed epics |
| Freshness | Jira pull, workspace scan, GitHub sync; amber after a day |

## Staleness badges
DoR check > 7 days · scans / pulls > 1 day · initiative unchanged > 30 days.

## Reports
Built in the browser from the current state; *Copy* or *Download .md*: Weekly status, Journey readiness,
initiative one-pager (initiative drawer).
